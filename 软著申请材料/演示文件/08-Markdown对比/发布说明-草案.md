# 文件对比工具 发布说明

版本：v1.3　发布日期：2026-10-21

## 一、本次更新

- 新增 Excel 表格对比，支持多 Sheet 与复合键
- 新增扫描版 PDF 的离线文字识别
- 导出报告保留原表列宽与表头样式

## 二、支持的文件类型

| 类型 | 扩展名 | 版面还原 |
| --- | --- | --- |
| 纯文本 | .txt | 不适用 |
| Word | .docx | 段落级 |
| PDF | .pdf | 逐页 |

## 三、启动方式

```bash
node serve.js
```

所有对比均在本机完成，文件不会上传到任何服务器。
