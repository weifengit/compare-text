# 文件对比工具 发布说明

版本：v1.4　发布日期：2026-11-22

## 一、本次更新

- 新增 Excel 表格对比，支持多 Sheet 与复合键
- 新增扫描版 PDF 的离线文字识别
- 导出报告保留原表列宽与表头样式
- 新增网页对比，可直接把网址粘进文件框
- 新增 Markdown 渲染预览与差异标注
- 支持把文件直接拖进界面完成对比

## 二、支持的文件类型

| 类型 | 扩展名 | 版面还原 |
| --- | --- | --- |
| 纯文本 | .txt | 不适用 |
| Word | .docx | 段落级 |
| PDF | .pdf | 逐页 |
| Markdown | .md | 源码行级 |
| 网页 | .html / 网址 | 逐页 |

## 三、启动方式

```bash
node serve.js 8080
```

所有对比均在本机完成，文件不会上传到任何服务器。
